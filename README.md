# Principles of Constructor Dependency Injection

This lightweight sample project illustrates the core principles of constructor dependency injection (DI) in .NET Core. It demonstrates how to inject services into controllers and classes, decoupling dependencies and enhancing testability and maintainability. The repository serves as a clear and concise learning tool for those looking to grasp the fundamentals of DI, service lifetimes (Transient, Scoped, Singleton), and best practices for clean, modular application design in ASP.NET Core environments.
